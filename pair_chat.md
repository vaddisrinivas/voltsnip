# 🤝 Pair Programming Chat

> **How to use**:
> 1. Type your message after the last `---`
> 2. Save the file (`Cmd+S`) — Claude responds in seconds
> 3. Open **Markdown Preview** (`Cmd+Shift+V`) for live formatted view
>
> The watcher also sees which files you're editing in real time.
